# One-year plan — framework + one prototype cell

**Horizon:** 2026-09-18 → 2027-09-18  
**Budget band:** **$0.4–1.2 million USD (ESTIMATE)** — see `cost_and_deployment_models/cost_model.md`  
**Build object:** framework artifacts + **one** digital-twin cell  
**Not:** a global map, a hardware mesh, or a second commercial species.

Commercial FishAI remains **ONE×ONE×ONE×ONE**. This year the observatory *learns how to be honest*; it does not “track everything.”

---

## 1. Year-1 outcomes (pass/fail)

### Must exist (framework)

- Species support-tier grammar T0–T6 applied honestly (most example taxa remain T0–T2).  
- Observation-modality catalog with physical limits.  
- Lawful source catalog (no bulk ingest).  
- Evidence-typed output contract + UI spec.  
- Cost model that keeps hardware last.  
- Privacy/publish classes (PUBLIC … NEVER_PUBLISH).  
- Validation protocol that forbids random CV and SST-as-fish.

### Must exist (prototype cell) — **P0-WILLAPA-MGIGAS-OSI72**

A living twin of **Pacific oyster operational-stress conditions** in the **Willapa Bay system** (or the founder-locked named growing-area set):

| Estimates | Does not estimate |
| --- | --- |
| Tide/emersion timing | Number of oysters (operator already knows plantings) |
| Heat×emersion coincidence (air + water as available) | Food safety, NSSP, Vibrio, biotoxin |
| Wave/wind **workability** vs a stated rule | Navigation / “safe to go” |
| Relative 24–72h **Category D** OSI-72 vs comparable windows | Mortality % guarantee |
| UNKNOWN when station too far / inputs stale | Harvest open/closed as a model |

**Delivery:** daily email + 1-page PDF + 30-second outcome form. Scientist evidence drawer optional.

### Year-1 is a **success** if all of:

1. Rights-approved **as-of replay** of public covariates for the cell (tiny store, not a lake).  
2. ≥**3** permissioned farms (or a documented failure to recruit after a real attempt).  
3. **≥14 consecutive days** of human-QA’d briefs, then **≥60 issuance days** prospective (need not be calendar-contiguous).  
4. Outcome completeness **≥60%** of work days among active partners.  
5. Every brief carries evidence class + 14 contract fields + “not food-safety.”  
6. Rule/baseline **documented**; ML either unused or **fails to ship** if it does not beat the baseline on time-forward evaluation.  
7. **No** public biological heatmap; **no** hardware fleet purchased.

### Year-1 is a **fail** if any of:

- Briefs are indistinguishable from “open NANOOS + tides” **and** 0/3 partners would change a crew call (after interviews + 14-day test).  
- Partners only want harvest-legal / Vibrio guidance.  
- Outcome logging refused.  
- A food-safety or abundance claim ships.  
- Scope expands to a second species or a global UI to “use the budget.”  
- EK80/DAS/AUV/VHR purchased without a written residual-uncertainty experiment.

**Off-ramps are successes.** A documented NO-GO is a Year-1 scientific win.

## 5. Scientific honesty this year

**Observable:** tides, NWS, some in-situ T/S/DO, partner work/mortality notes.  
**Inferable:** relative heat×emersion stress **rank**, with large microclimate error.  
**Forecastable:** physical drivers 24–72h (weather/tide); **not** mortality %.  
**Requires infrastructure:** on-lease thermistors if station distance kills skill.  
**Unproven:** that farms will pay.  
**Speculative:** any global biological nowcast.  
**Not measurable now:** exact bag-level mortality from satellite SST.
