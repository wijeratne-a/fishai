# Three-year plan — a few taxa operational-ish

**Horizon:** 2026-09-18 → 2029-09-18  
**Prerequisite:** Year-1 P0 did not fail closed. If it did, this file is **void** until a new ONE×ONE×ONE×ONE is chosen.

**Meaning of “operational-ish”:** support tier **T4 approaching T6 in a named cell** — prospective issuance, calibrated uncertainty, rights, partner feedback — **not** “we run a model in production on a global grid.”

---

| Object | Count | Claim allowed |

| Operational-ish **cells** | **1–4** | Each still one species × one geography × one user type × one decision |
| Taxa with T6 | **0–2** | Only with prospective skill + reviewer |

Commercial FishAI, if alive, is **still** one SKU until a **written** traction expansion (second farm basin ≠ second species).

## 2. Year-by-year

### Year 1 (see `1_year_plan.md`)

Framework + **P0-WILLAPA-MGIGAS-OSI72**. Budget **$0.4–1.2M** ESTIMATE.

### Year 2 — harden or stop

**If oyster G3–G5 pass:**

- Automate covariate pull; human QA sample, not 2 hours/farm/day.  
- Add leases **only** inside the locked geography until automation holds.  
- Optional: on-lease **existing** sensor export; still no mesh.  
- Optional **scientific** (not commercial) second slice: either (a) same species, second named basin as a **transfer test**, or (b) a **private** lobster CPUE cell **if** DUAs exist and AIS is banned as abundance.  
- Chinook public encounter map remains **red-teamed off** unless season+logs+coarsening all exist.

**If oyster fails WTP but science is clean:** keep the cell as a **research twin** (cheap) or archive it. Do **not** spend Year-2 budget on hardware to rescue a product nobody wanted.

**Budget Year 2:** **$0.5–1.5M** ESTIMATE if scaling the cell; **<$0.3M** if research-only.

### Year 3 — few taxa, still cells

Pick **at most two** additional operational-ish slices from a shortlist that has labels:

1. Oyster ops-stress in a **second** named estuary (culture-stratified).  
2. Lobster **Category C** next-trip CPUE, one NMFS statistical area, **operator-private**.  
3. A **bloom / HAB extent** cell that is REMOTELY DETECTED and **not** sold as food-safety.  
4. A **coarsened** mammal acoustic occupancy cell with NEVER_PUBLISH on tracks.

Each slice repeats the Year-1 loop (rights → partners → baseline → prospective → kill). **No shared neural net required.** Shared **architecture** (layers, replay, evidence UI) is the reuse.

**Budget Year 3:** **$0.8–2.0M** ESTIMATE for 2–4 cells software-heavy; add **$0.1–0.5M** per named sensing experiment (partner sonar export or eDNA calibration), not before residual uncertainty is written down.

**Cumulative 3-year:** **$1.5–4.5M** ESTIMATE if all three years are “go.” Far less if Year-1 fails.

- Claim inflation detected in the wild (treat as Sev-1).

- Model loses to seasonal climatology after two honest iterations.  
- Founder expands to “all Washington oysters” or “all salmon” without new labels.
