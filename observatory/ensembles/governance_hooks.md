# Governance hooks — ensembles

**Date:** 2026-09-18  
**Status:** Ship-blocks for any ensemble-shaped output (brief, API, map, deck).  
**Rule:** an ensemble **mean is not a product** until members are carded, claims are bounded, and disagreement is visible.

This agent cannot clear red-team BLOCKERs. It can only refuse to specify a path that bypasses them.

---

## 1. Must not ship an ensemble mean without

Check all boxes. v0 default is **mean suppressed**, so a W1 brief can still show **members** if (and only if) a later founder lock + rights + contract allow a **baseline-packaged** brief — that is quality’s non-ML GO path, not an “AI ensemble” GO.

| # | Hook | Fail closed |
|---|---|---|
| G1 | **Model card per member** (`card_id`, target, quantity class, horizon, grain, universe, inputs, as-of rule, never-claims, version, training cutoff or `not_fitted`, known limitations, culture stratum) | No mean; no “consensus” copy |
| G2 | **Prediction contract** 14 fields + Category D + oyster never-claims | No customer-facing number |
| G3 | **Disagreement panel** showing each member (map split or email table) | Mean-only heatmap is a ship block |
| G4 | **Prohibited-claim scan** (§3) on title, legend, SMS, and tooltip | Block send |
| G5 | Red-team oyster food-safety **wall**: DOH/NSSP/Vp **not in the mean** | Separate module or no brief |
| G6 | Privacy: public grain coarsened; **no lease performance**; no isolating aggregation | Strip or withhold |
| G7 | Weight basis ≠ in-sample; label `UNWEIGHTED_PLACEHOLDER` until prospective slice id exists | Do not say “learned weights” |
| G8 | Human domain reviewer named for residual HIGH (shellfish + NSSP) | Agents cannot self-clear |

**Today (2026-09-18):** G1 cards are **templates only** (nothing fitted). G8 unnamed. Mean **must not** issue. Fixtures are research objects, not briefs.

```text
class_id                MC-RULE | MC-CLIM | MC-HUM
baseline_id             B4-v0 | B12-v0 | B5-v0
quantity_class          operational_stress_indicator
category                D
label                   ops_disruption_72h
not_in_card             food_safety, harvest_legality, abundance, percent_dead, SST_as_body_T
primary_mechanism       B4: air x daytime emersion x solar and/or partner wave rule
                        B12: month x growing_area event rate
                        B5: pre-brief operator intent
forbidden_mechanism     SST >= 19 C kill law; Hobday MHW as default 72h oyster rule; DOH open/closed
fitted                  false
weight_basis            UNWEIGHTED_PLACEHOLDER
```

No card ⇒ member `e_i = 0` and `cannot_issue`.

## 3. Prohibited claims (ensemble-specific additions)

Inherit `prediction_contract.md` §0. Also forbid:

| Claim | Why |
|---|---|
| “AI ensemble,” “digital twin consensus,” “models agree the oysters are safe” | v0 is two baselines; safety is DOH |
| A single 0–100 or 0.73 blended score | Opaque; false precision |
| “Habitat and catch combined for robustness” | Incomparable quantities |
| “Disagreement is low, therefore High confidence” | \(D\) is not calibration |
| Public “farms that disagree” leaderboard | Privacy |
| Mean band without the High member when \(D \ge 0.5\) | Hide-the-split |
| Candidate classes drawn as live members | False stack |
| Up-tier: T2 registry oyster → T6 because an ensemble spec exists | Factory rule |
