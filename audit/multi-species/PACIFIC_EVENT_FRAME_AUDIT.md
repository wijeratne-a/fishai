# Pacific event-frame audit

The full-year downloads for Hawaii 2024, American Samoa 2023, CNMI/Guam 2022, and the Pacific Remote Islands 2023 contain positive `COUNT` values and no zero counts.

A three-row Hawaii 2024 sample shows the event fields that were missing from the first column list: `SITEVISITID`, `REPLICATEID`, `REP`, and `METHOD`. The sample method value is `nSPC`. Those fields can identify a replicate. They do not add zero rows.

A non-detection cannot be built by listing species that never appear. This table does not publish the species universe that was searched and missed. Status for all four Pacific datasets: `POSITIVE_ONLY`.
